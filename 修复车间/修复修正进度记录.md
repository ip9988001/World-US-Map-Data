### 二、KY / NE / NM / OK 根因：运行被取消（不是代码错）

逐轮核对 10-18 以来的运行：
```
10-18 08:26  matrix  KY cancelled / NE cancelled / NM cancelled / OK cancelled / NV success / ID failure
10-19 08:37  matrix  KY cancelled / NE cancelled / NM cancelled / OK cancelled / ID cancelled
10-19 08:45  matrix  KY cancelled / ID success
10-19 10:58  matrix  KY cancelled
```
- 这四次都是**整个 run 被 cancel**（run 级 conclusion=cancelled），已完成的 job（NV success）保留，运行中的被取消。
- 两次 run 的时间戳咬得很死：前一个 run `updated_at=10:58:28` 被取消，后一个 `created_at=10:58:43` 建立 → 典型的“重开一轮把上一轮顶掉”。
- 结论：**数据没坏、代码没报错，只是没收尾**。KY/NM 的 NAD 已 100% 完成（只差 OVT/OA/TIGER），NE 差 36 个县，OK 从未开始。

### 三、NV 根因：NAD 上游对部分县的「多边形相交」查询失效

对同一个 NAD 图层（FeatureServer 点图层，SR=3857）做四组对照（本次实测）：

| 对象 | 信封（bbox）计数 | 多边形计数 | 判定 |
|---|---|---|---|
| NV 全州 bbox | 65,424 | — | 正常 |
| NV Clark 县 | 59,212 | **0** | ❌ 失效 |
| NV Esmeralda 县 | 有值 | **0** | ❌ 失效 |
| NH Belknap 县 | 2,360 | **0** | ❌ 失效 |
| MN Hennepin 县 | 无（未查） | 408,414 | ✅ 正常 |
| DE New Castle 县 | 299,402 | 275,961 | ✅ 正常 |
| SD Minnehaha 县 | 63,979 | 63,636 | ✅ 正常 |

排除项（都试过了，仍为 0）：
- 环方向（原样 / 逆序）→ 都是 0
- 环未闭合 → 补闭合后仍 0（实测环本来就是闭合的，首尾点相同）
- 坐标系（inSR=4326 / 转 3857）→ 3857 反而报参数错
- where 条件（1=1 / State='NV'）→ 都是 0

结论：**不是我们的代码问题**，是上游该视图对 NV/NH 这些县的多边形空间查询返回 0（信封查询正常）。这解释了两件事：
1. NV 已封印却是 `counties_ok=0 / counties_empty=17`，65,424 行全部落进 OUTOFSTATE；
2. NH 也是同一类（历史上就是“county 全空 + 数据全在溢出包”）。
