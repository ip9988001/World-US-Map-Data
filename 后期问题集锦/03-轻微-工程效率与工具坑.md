# 🔵 轻微 · 工程效率与工具坑

> 判断标准：不影响数据正确性，只拖慢开发/诊断速度，或导致误判后白干活。

## P13 · GitHub 对 in_progress run 的日志一律 404 🔴（不可修，只能绕）

**现象**：想通过日志诊断卡死的 job —— 拉不到。**不只是 in-progress 的 job，已 success 的 job 也一样**（因为按 run 锁）。

**绕过**：① 等 run 结束；② 用 Release 账本（STATUS.updated_at）代替日志判活；③ 用 artifact（job 结束才上传）。

**教训**：诊断大州卡死时，资产数/账本是唯一可用的实时信号——但**资产数也不可靠**（产物最后统一上传）。

## P14 · `duckdb.sql()` 新版没有 `fetchone()` ✅

**现象**：发布物抽查里所有 parquet 抽样都报 `AttributeError: Relations no longer have fetchone()`。

**根因**：duckdb 新 API 返回 Relation，不再有 `fetchone()`。

**处置**：改 `fetchall()`（commit 随 release-quality-audit 修复），重跑后 IL/GA/MI/OK/HI 的 parquet 全部 ok。

## P15 · 本机探针给出假结论（WAF 403 / 跨洋延迟）✅

**现象**：本机（香港 VPS）TIGER 探测**一律 403**，NAD count 冷启动 49.8 秒；同一时刻 runner 侧 TIGER 200、NAD 9.6 秒。

**根因**：探针测的是它脚下机器的网络，不是上游。本机 IP 被 census.gov WAF 拦、且跨太平洋延迟高。

**处置**：探针全部搬到 runner（`preflight-upstream.yml`），本机 cron 删除。**铁律：探针必须和干活的机器同一台。**

## P16 · 哨兵私有协议（8787 端口 + outbox + 文件队列）⬜

**现象**：本机 `sentinel.py` 开 `127.0.0.1:8787` 收事件、写 outbox、`push.mjs` 轮询 outbox 发送。

**问题**：要开端口、管 token、维护三份文件状态、外面看不见它在干什么。

**处置**：废弃。改为「GitHub Issue 作信箱 + 本机 inbox.py 轮询 + pi 按需推送」。

## P17 · agent_fix 自动改代码与人工改代码并行 ⬜

**现象**：2026-10-22 一天内，哨兵自动修 + 会话人工修交替产生 9 个 commit（5906bae / 1d663c5 vs 0aee8e6 / cf7675c / 915c59f / da26c9b / 70278a9 / 91d0d89 / 35dc065），未冲突属运气。

## P18 · 每产出一个县片就 POST 一次本机（3000+ 跨洋请求）✅

**现象**：`fetch_state_raw.py` 的 `_notify()` 每县 POST `secrets.SENTINEL_URL`（本机公网入口）。

**影响**：3000+ 县 = 3000+ 次跨洋请求；本机一挂事件全丢（静默失败）。

**处置**：`9324fd4` 删掉 workflow 里的 `SENTINEL_URL` / `SENTINEL_TOKEN`（`_notify` 在 URL 为空时直接 return，抓取代码零改动）。验证：`sentinel.log` 70 秒零增长。

## P19 · `gh run list --json jobs` 字段不存在 ✅

**现象**：`pipeline_audit` 的"在跑哪些州"恒为空，连带 B2（24h 配额）、B3（失败无接管）从未真正工作过。

**根因**：`gh run list --json` 不支持 `jobs` 字段 → 整个 JSON 解析失败 → `runs_recent()` 返回空列表。

**处置**：去掉 `jobs` 字段，活跃 run 改用 `gh run view` 单独拉；且只认 `status in (queued,in_progress)` 的 job（否则会把历史失败的州也算成"在跑"）。

## P21 · inbox.log 每行写两遍 ✅

**现象**：`log()` 既 `print` 又写文件，加上 cron 的 `>>` 重定向 → 每行出现两次。

**处置**：`log()` 加 `sys.stdout.isatty()` 判断，cron 下不 print。
