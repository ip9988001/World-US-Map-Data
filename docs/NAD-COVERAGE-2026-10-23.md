# 一仓 NAD 真实覆盖率核查报告（2026-10-23）

> 一句话：**NAD 里只有 24 个州的数据真的落在本州境内，其余 28 个州的点绝大部分跑到州界外去了。**
> 这不是文件缺失，是「下载到了、位置全错」或「上游本来就没有」。

## 一、为什么必须重做这次核查

上一轮 MANIFEST 里写着 `coverage_pct: 100.0`，那个数字来自「县片行数 + 溢出包行数 = 上游 state count」。
问题是**溢出包装的是外州点**，把它算进本地产出，账做平了、事实没对上。

复现到的上游异常（2026-10-23 实测）：

- 同一个 bbox 连打 5 次 `returnCountOnly` + `outFields`，全部超时
- Cass County MI：`returnCountOnly` 返回 883，同一 bbox 的 `outFields` 查询返回 **0 条 features**
- NH 全州 bbox 返回 354,804 行，State 字段分布 `MA 140,838 / ME 115,675 / VT 98,291` —— **零条 NH**
- Rockingham County NH 的 bbox 查询 110,783 行，抽样全是 MA Essex 的点

结论：**不能向上游问「每县有多少数据」**，只能核对手里握住的东西。

## 二、核查方法（可复现）

```
python3 tools/nad_local_matrix.py raw-US-XX-v1     # 单州：NAD 实物 × TIGER 县界逐点判定
python3 tools/write_nad_truth.py                   # 把结果写回各 Release 的 MANIFEST
python3 tools/make_nad_coverage_report.py          # 生成本报告
```

做法：把 Release 里已下载的 NAD 数据逐行取出经纬度，用该州 TIGER 县界（3,142 县）做点内判定，
算出每个县真实有多少点落在境内。**不问上游、不依赖 API、不受限流影响。**
性能上用 shapely 2.x 的向量化 `contains_xy`：CA（240 万点 × 58 县）98 秒，全 52 州并行 3 路 45 分钟。

## 五、两类缺陷必须分开处置

### 类型 1：下载到了，但位置全错（重抓无用）

特征是「总点数很大、州内点接近 0」，因为上游拿州 bbox 查询时返回的是**邻州点**。
重抓 100 次结果一样 —— 上游这个视图对这些州就是这个行为。

- **HI**：0 点里只有 0 落在境内（—）
- **MI**：0 点里只有 0 落在境内（—）
- **MS**：470,759 点里只有 3 落在境内（0.0%）
- **NH**：354,804 点里只有 0 落在境内（0.0%）
- **NV**：65,424 点里只有 0 落在境内（0.0%）
- **PA**：2,437,907 点里只有 1,053,974 落在境内（43.23%）
- **WV**：3,006,336 点里只有 1,019,948 落在境内（33.93%）
- **GA**：700,572 点里只有 205,071 落在境内（29.27%）
- **SC**：1,069,405 点里只有 212,291 落在境内（19.85%）
- **ID**：614,754 点里只有 88,631 落在境内（14.42%）

### 类型 2：上游本来就没有那些县（NAD 自愿申报制）

特征是「州内占比 100%，但有点的县数远少于县总数」。这些县从来没向联邦提交数据，
空壳文件不是抓取失败，是客观事实。典型：

- **GA**：159 县里 157 县无数据（2/159 有数据，州内占比 29.27%）
- **MI**：83 县里 83 县无数据（0/83 有数据，州内占比 None%）
- **MO**：114 县里 81 县无数据（33/114 有数据，州内占比 100.0%）
- **MS**：82 县里 81 县无数据（1/82 有数据，州内占比 0.0%）
- **SD**：66 县里 59 县无数据（7/66 有数据，州内占比 69.18%）
- **LA**：64 县里 59 县无数据（5/64 有数据，州内占比 68.41%）

## 六、给下游（二仓）的处置建议

| 分级 | 州数 | 建议 |
|---|---|---|
| A（≥95%） | 24 | NAD 可直接作为本州地址源使用 |
| B（80~95%） | 8 | 可用，但需按县剔除州界外的杂点 |
| C（5~80%） | 15 | 不可直接使用；本州缺口用 Overture（州内可精确筛）补齐 |
| D（<5%） | 5 | 视同无 NAD；整州改用 Overture + OpenAddresses |

**A 级州清单**：CA、IL、IN、KY、MD、ME、MO、NC、NJ、NY、OH、TN、TX、TX、VA、AZ、WY、CO、AK、WA、MA、UT、MT、AL

**D 级州清单**：HI（无数据包）、MI（无数据包）、MS（近乎全废）、NH（近乎全废）、NV（近乎全废）
